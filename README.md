# 볼링 연습일지

휴대폰에서 쓰는 볼링 연습 기록 앱이에요. 서버 없이 **기록은 각자 휴대폰(브라우저) 안에만** 저장돼요.

**주소:** https://sunboys20.github.io/bowling-diary/

## 휴대폰에 설치하기
**설치 링크:** https://sunboys20.github.io/bowling-diary/?install=1 — 이 링크를 나눠 주면, 누르는 순간 설치 방법이 바로 떠요.
1. 안드로이드(크롬·삼성 인터넷): **[앱으로 설치]** 단추 → [설치]. 단추가 없으면 메뉴 → [홈 화면에 추가].
2. 아이폰(사파리): 안내 그림의 화살표대로 **[공유] → [홈 화면에 추가] → [추가]**.
3. 카톡 안에서 열었으면 **[크롬으로 열기]**(아이폰은 [사파리로 열기])를 먼저 눌러요. 카톡 안에서는 설치가 안 돼요.
4. 처음 열면 사용자1~6 중에서 골라요. 이름은 [설정]에서 바꿔요.

그림으로 보는 처음 설정 순서: https://sunboys20.github.io/bowling-diary/help.html (앱 오른쪽 위 ? 단추)

## 기능
- 일지: 날짜 · 볼링장 · 레인 · 오늘 볼 · 메모, 하루 최대 10게임
- 점수판: 프레임마다 투구를 누르면 누적 점수, 스트라이크 · 스플릿 · 오픈 수가 자동으로 계산돼요. 점수만 적을 수도 있어요
- 중간 점수 고치기: 누적 점수 칸을 눌러 직접 고쳐요. 뒤 프레임도 같은 만큼 바뀌고, 고친 칸은 노란색으로 보여요
- 게임마다 점수판 사진 1장
- 사진으로 자동 입력 (AI): [설정]에 Anthropic API 키를 넣으면, 사진을 읽어 점수판을 채우고 사진의 누적 점수와 맞는지 검산해요
- 내 볼: 이름, 무게(lb), 원핸드/투핸드
- 기록지: A4 한 장으로 인쇄하거나 PDF로 저장해요
- 통계: 평균, 최고점, 월별·볼별 기록
- 백업: 기록을 파일로 저장하고 불러와요 (휴대폰을 바꿀 때)

## 알아 둘 것
- 기록은 이 사이트에 올라가지 않고 **각자 휴대폰에만** 있어요. 다른 사람에게 주소를 줘도 내 기록은 보이지 않아요.
- 인터넷 기록을 지우거나 휴대폰을 바꾸면 기록이 사라질 수 있어요. **[설정 › 백업 파일 저장]**을 가끔 해 두세요.
- AI 키는 그 휴대폰에만 저장되고 백업 파일에는 들어가지 않아요. 콘솔에서 월 사용 한도를 정해 두세요.
